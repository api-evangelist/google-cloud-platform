- [Google Cloud Platform Operations API](https://apis.io/apis/google-cloud-platform/google-cloud-platform-operations-api/) — Long-running operations returned by Resource Manager API methods. Some methods return an Operation resource to track the progress of asynchronous requests.
- [Google Cloud Platform Organizations API](https://apis.io/apis/google-cloud-platform/google-cloud-platform-organizations-api/) — Manage Google Cloud organizations. An organization is the root node in the Google Cloud resource hierarchy, typically representing a company or business…
- [Google Cloud Platform Projects API](https://apis.io/apis/google-cloud-platform/google-cloud-platform-projects-api/) — Manage Google Cloud projects. A project is the base-level organizing entity in Google Cloud and is required to use most Google Cloud services. Projects…
- [Google Cloud Platform TagBindings API](https://apis.io/apis/google-cloud-platform/google-cloud-platform-tagbindings-api/) — Manage tag bindings that associate tag values with Google Cloud resources. Tag bindings connect tag values to specific resources in the hierarchy.
- [Google Cloud Platform TagKeys API](https://apis.io/apis/google-cloud-platform/google-cloud-platform-tagkeys-api/) — Manage tag keys used to organize and categorize Google Cloud resources. Tag keys define the namespace for tag values that can be attached to resources.
- [Vertex AI API](https://apis.io/apis/google-cloud-platform/vertex-ai-api/) — Unified AI platform for building, deploying, and scaling ML models.
- [Google Cloud Platform Tag Values API](https://apis.io/apis/google-cloud-platform/google-cloud-platform-tag-values-api/) — Manage tag values associated with tag keys. Tag values are the specific labels that can be bound to resources through tag bindings.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Google Cloud Platform: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
